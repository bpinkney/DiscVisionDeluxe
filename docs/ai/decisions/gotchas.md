# Hard-Won Debugging Facts — DiscVisionDeluxe
Append-only. Add entries when something non-obvious breaks. <=8 lines per entry.

---

## SpinnakerNET_v140.dll is C++/CLI mixed-mode
Cannot be referenced as a managed assembly regardless of Inspector plugin settings. Always shows Type: Native and produces CS0246. Use P/Invoke against SpinnakerC_v140.dll instead. All bindings in SpinnakerCAPI.cs.

## Spinnaker DLL Dependencies
12 DLLs required in Assets/Plugins/Spinnaker/ (all Native, x64 only, Editor+Standalone).
vcomp140.dll comes from C:\Windows\System32\ — NOT in Spinnaker bin64.
After adding/changing any native DLL: fully close and reopen Unity. A full PC reboot was needed once to seat the Spinnaker kernel filter driver.
Find missing DLLs: Dependencies tool (drag DLL in, red entries = missing) + Process Monitor (Process=Unity.exe, Result=NAME NOT FOUND, Path contains Spinnaker).

## spinImageConvert absent in Spinnaker 3.2
Does not exist in the C API. Configure camera to output Mono8 directly via GenICam node map: SetEnum(hNodeMap, "PixelFormat", "Mono8") in InitCamera(). No runtime conversion needed.

## TextureFormat.R8 displays as teal/cyan in Unity 6 URP
Not grayscale. Preview texture must use TextureFormat.RGB24 with manual byte expansion (each Mono8 byte → R=G=B). Raw byte[] passed to AprilTagDetector stays as single-channel Mono8 — do not expand there.

## Emgu CV cvextern.dll meta file
NuGetForUnity installs managed Emgu.CV.dll but NOT cvextern.dll (native ~80MB). Must be placed manually in Assets/Plugins/EmguCV/. The .meta file auto-generated by Unity may be nearly empty — write it explicitly: Native, x86 UNCHECKED, Editor (CPU x86_64, OS Windows), Win64 (CPU x86_64), all others off. Full Unity restart required after placing DLL.

## libusb-1.0.dll hidden dependency of cvextern.dll
Symptom: TypeInitializationException for ArucoInvoke even after cvextern.dll is correctly configured.
Find via Dependencies tool (red entry in cvextern.dll tree). Source: libusb GitHub releases VS2019/MS64/dll/libusb-1.0.dll. Same plugin settings as cvextern.dll. Full restart required.

## Emgu CV 4.12 API — three gotchas
1. Dictionary: use integer cast `new Dictionary((Dictionary.PredefinedDictionaryName)20)` — enum names for AprilTag36H11 are missing.
2. ArucoDetector class does not exist — use `ArucoInvoke.DetectMarkers(mat, dict, corners, ids, detParams, rejected)`.
3. DetectorParameters: `new DetectorParameters()` zero-inits all fields; OpenCV asserts markerBorderBits>0 and rejects. Use `DetectorParameters.GetDefault()` factory method instead.

## solvePnP CopyTo dimension mismatch (zero tvec bug)
Symptom: all tvec values are (0,0,0) despite tags being detected.
Root cause: `rvecMat.CopyTo(new Matrix<double>(rvec))` creates a 1×N row vector, but solvePnP outputs a 3×1 column vector. CopyTo silently fails on dimension mismatch.
Fix: `new Matrix<double>(3, 1)` as solvePnP output; read with indexer `rvecOut[0,0]` etc.

## Camera dropdown: CameraMode enum vs UI order mismatch
CameraMode enum order (Overview=0, Follow=1, Side=2, Overhead=3) does not match UI choices order (Follow=0, Side=1, Overhead=2, Overview=3). Always use ModeToIndex()/IndexToMode() in ThrowParameterPanelController — never cast directly. Also: `dropdown.index = x` does not fire RegisterValueChangedCallback; call SetMode() explicitly on startup.

## BayerRG8 at 522fps — USB bandwidth saturation
Causes rapid camera disconnect/reconnect (720×540×522fps ≈ 200MB/s). Reverted to Mono8 at 290fps. To revisit: need USB host controller bandwidth check + CvtColor(BayerRG→Gray) step + verify resolution ROI can reduce bandwidth.

## DiscVisionDeluxe.UI.asmdef missing Unity.TextMeshPro reference
Symptom: CS0246 on TMP types in MiniMap.cs. Fix: add Unity.TextMeshPro to DiscVisionDeluxe.UI.asmdef references.
